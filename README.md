# Partner Git Practice

Tiny site used in a 60-minute hands-on workshop for Git, GitHub, Node.js, Vercel, and Claude Code.

**Homepage headline lives in** [`index.html`](./index.html) — that is the only file partners should change during the session.

## Local preview

```bash
npm install
npm run dev
```

Open the URL Vite prints (usually `http://localhost:5173`).

## Workshop docs

| Doc | Audience |
| --- | --- |
| [workshop/PREWORK.md](./workshop/PREWORK.md) | Partners — install tools 24–48h before |
| [workshop/FOLLOW_ALONG.md](./workshop/FOLLOW_ALONG.md) | Partners — numbered steps during the hour |
| [workshop/CHEAT_SHEET.md](./workshop/CHEAT_SHEET.md) | Partners — one-page command reference |
| [workshop/FACILITATOR.md](./workshop/FACILITATOR.md) | You — publish repo, Vercel, sample PR |
| [workshop/DRY_RUN_NOTES.md](./workshop/DRY_RUN_NOTES.md) | You — timing + failure fallbacks |

## Mental model

GitHub = shared Drive for code · branch = your copy · PR = please accept my edits · Vercel = live site that updates when `main` changes.
